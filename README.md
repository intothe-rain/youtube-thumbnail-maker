# YouTube 썸네일 메이커

이미지를 업로드하고 6가지 템플릿 중 하나를 선택한 뒤 텍스트를 수정하여 PNG로 다운로드하는 웹앱.

## 기능

- 이미지 업로드 (클릭 / 드래그 앤 드롭)
- 6가지 템플릿 (풀 오버레이, 다크 오버레이, 배너, 분할, 임팩트, 네온 글로우)
- 실시간 미리보기
- 720p(1280×720) / 1080p(1920×1080) PNG 다운로드
- 스타일 갤러리: 실제 유튜버 참고 썸네일 6종 비교

## 기술 스택

Vanilla HTML / CSS / JavaScript, HTML5 Canvas API

## 배포

Cloudflare Pages — `main` 브랜치 push 시 자동 배포
