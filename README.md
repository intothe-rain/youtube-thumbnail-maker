# YouTube 썸네일 메이커

침착맨 스타일 썸네일을 만드는 웹앱.

## 기능

- 배경: 이미지 업로드 또는 색상 선택
- 인물 사진: 업로드 후 캔버스에서 드래그 이동 + 크기 조절
- 텍스트: 메인 제목(대형 좌측) + 서브 제목(하단 좌측), 흰색 + 검정 외곽선
- 다운로드: 720p(1280×720) / 1080p(1920×1080) PNG

## 기술 스택

Vanilla HTML / CSS / JavaScript, HTML5 Canvas API

## 배포

Cloudflare Pages — `main` 브랜치 push 시 자동 배포
